# Laravel SSLCommerz Checkout Sandbox Demo
## Install
1. [ ] composer php
2. [ ] php 8.3
3. [ ] Nginx or Apache


## Run Project

1. If you want to run project using command then run. It will create a new url 127.0.0.1:8000
   `php artisan serve`
